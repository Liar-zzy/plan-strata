## 预算恢复：已补指引，仍不是运行时强制

原指引要求跨重试/Worker 累计预算，但没有明确交接和恢复时保存哪些消费信息；
Worker 模板的返回内容也未要求预算用量。这是可能导致跨会话漏计的说明缺口，

现补充：在现有 progress 保留已用/剩余总量及未释放资源预留；Worker 回报本次
用量与未结束作业；恢复时对照记录/日志/作业句柄核对。未知消费不当作零，只有
能够确认下一动作仍在额度内才继续。技能入口增加“恢复返修闭环”的读取条件。
没有新增预算表、协议字段或 Agent 调度代码。

另外放入一个非阻断建议/新增需求，观察是否被错误地塞入必须完成的范围。先补这类
行为证据，再决定是否扩展调度能力；此建议不等于已授权启动 Agent 或外部操作。
