# Plan Strata — 项目核心

为开发与科研提供轻量、可恢复的 Agent 计划工作流。保留 core → ex-plan → check，
明确进度权威位置、执行基线、证据适用范围和科研判断。一个计划可由多个 Agent 共用。

首轮只交付本地实验版技能、最小模板、只读校验工具和可复现的试用记录。
用户已要求“那你来试试”，授权本地实现与验证。原始会话保持私有；GitHub 发布
作为后续交付动作，本轮记录不宣称已经发布。

资源范围：本地文件、小型合成场景与有限的独立 Agent 前向试用。完成本轮列明的
行为检查即可收尾；不以长周期科研效果、生产级调度或所有客户端适配为结束条件。
