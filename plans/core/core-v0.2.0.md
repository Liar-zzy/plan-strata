# Plan Strata — 项目核心

为开发与科研提供轻量、可恢复的 Agent 计划工作流。保留 core → ex-plan → check，
明确进度权威位置、执行基线、证据适用范围和科研判断。一个计划可由多个 Agent 共用。

项目以独立、可安装的开源技能为交付物，配套最小模板、只读工具和可复现验证。
当前成熟度为 alpha；记录一致性和小规模行为试用不代表长期可靠性或科研结论成立。
原始私人会话不进入公开仓库。保持标准库运行依赖与单一进度维护者，不引入调度系统。
