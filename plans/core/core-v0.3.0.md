# Plan Strata — 项目核心

为开发与科研提供轻量、可恢复的 Agent 计划工作流。保留 core → ex-plan → check，
明确进度权威位置、执行基线、证据适用范围和科研判断。一个计划可由多个 Agent 共用。

交付独立可安装的开源技能、最小模板、只读工具和可复现验证。默认保持单 Agent
流程；适合委派且用户选择时，使用与交接渠道无关的任务单、隔离执行和集成验收。
Manager 是单一进度维护者。Git、Issue 或特定 Agent 平台均不是协议的前提。
保持标准库运行依赖；本阶段不实现常驻调度器、分布式锁或外部平台适配器。

成熟度保持 alpha。小规模试用不代表长期可靠性、科研结论或跨客户端行为成立。
原始私人会话不进入公开仓库；外部发布、资源消耗和合入主分支按用户授权分别处理。
