# Plan Strata — 轻量、可恢复的项目与科研管理

继承 core-v0.3.0.md 的目标：提供独立可安装的开源 skill、最小模板和标准库只读
校验器，把意图、执行、进度和实际证据连接起来。开发与科研各自保留验收含义。
默认单 Agent；并行交接需用户针对当前批次明确选择，Manager 是单一进度维护者。
Git、GitHub 和特定 Agent 平台不是前提，不实现调度器、分布式锁或预算引擎。

2026-09-10 用户要求移除哈希记账并授权复核后推送新版。新记录使用 schema 2，
不计算或要求文件内容哈希，也不要求为普通记账额外 commit 或复制整个工作区。
保留计划版本/路径、任务绑定、真实检查、有限预算与必要历史；利用已有版本控制
或交付副本即可。相关修改后的证据适用性由 Agent/Manager 显式复核、重开并复测。
工具只检查结构与路径，不自动检测内容变化、不证明测试充分或科研结论成立。

成熟度保持 alpha。旧 schema 1 历史不重写、不静默降级；按新迭代显式迁移。
原始反馈和私人会话不公开。commit/push、外部任务发布、main 合并及安装升级
分别遵循当前授权，过去迭代的许可不自动继承。
