# Plan Strata — 轻量、可恢复的项目与科研管理

继承 core-v0.4.0.md 的目标与无哈希 schema 2：提供独立可安装的 skill、最小模板
和标准库只读校验器，连接计划、任务绑定、实际证据与跨会话交接。开发与科研
保留各自验收含义；已使用的计划与检查保持历史，不自动为后续改动背书。

2026-09-15 用户批准根据反馈更新指令边界。仅在明确要求建立 Plan Strata 计划，
或处理已纳入其管理的工作时触发；绑定、就绪状态和工具可用性不授予执行权限。
当前请求与可追溯到用户批准批次的派工，在原范围内复用授权。局部阻塞只暂停
受影响动作，继续独立的授权工作。

默认单 Agent；并行需已获准的批次。宿主派工消息与绑定任务卡可共同构成完整交接，
沿用项目的独占分配方式，Agent ID 返回后登记派工回执。获准 Manager 决定接受，
progress 只由项目指定的单一 writer 修改，默认由 Manager 兼任。角色可以由同一
Agent 兼任，但每项动作仍受现有授权与写入范围约束。

Git、GitHub、哈希及特定 Agent 平台均不是前提，不实现调度器、锁或预算引擎。
工具仅检查结构与路径；实际验收及相关变更后的复核由获准角色完成。成熟度仍为
alpha；原始反馈不公开，提交、推送、发布与安装升级分别按当前授权执行。
