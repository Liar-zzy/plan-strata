# P002 — GitHub alpha 发布准备

承接 P001 的已完成技能，不改变其冻结计划与历史检查。用户要求英文介绍、
中英文 README、快捷安装，稍后再提供 push 指示。保持技能版本 0.1.0-alpha.1。

## T01 — 发布说明与安装交付

产物：英文 README.md、README.zh-CN.md、英文仓库简介和发布草稿、可复跑的安装
冒烟检查、最小 GitHub Actions 配置，以及本轮实际验收记录。

验收：两种语言覆盖相同功能与限制；安装命令采用已核对的上游接口，说明安装范围、
依赖和覆盖风险；隔离项目中的 Codex 与 Claude Code 安装包含完整技能包，安装后的
校验器能运行且与源文件一致；原有 20 项测试在 Python 3.10 和 3.14 下通过。
校验文档链接、工作流配置和本轮计划记录；检查待公开文件，保留私人会话的忽略规则。

本轮只检验安装文件和只读命令，不宣称客户端自动发现或跨客户端行为已通过。
远端空仓库的安装及 GitHub Actions 真正执行留待首次 push 后确认。安装试用仅在
新建临时目录进行，不修改用户全局技能配置。任务内已包含文档与包的联合验证，
无需重复建立独立集成任务。禁止本轮 push、创建 release 或修改 GitHub About。

停止边界：本地材料与上述验证齐备，向用户交付可复制的英文简介和安装命令；
不为发布准备扩展技能协议或补做长周期研究。
