# P007 — 可独立接手的 Issue 任务契约

2026-09-07 用户批准在 dev 小范围补齐规则、模板及 Issue → 新 worktree 的独立
接手验证。起点 abe41f2；本轮只做本地修复与隔离试用，不创建真实 Issue、推送、
合并主分支、发布或安装全局技能。允许在临时合成仓库内创建 Git 历史和 worktree，
并以新上下文 Agent 验证任务交接。此授权不继承 P006 的 commit/push 权限。

## T01 — 交接说明、模板与入口验证

明确所选渠道中的任务本身必须足以独立接手，详细材料需固定版本且接收者可访问。
区分任务说明完整、依赖就绪、实际领取；支持先发布未领取的完整任务，领取时只做
分配登记。依赖未满足或关键材料不可访问时明确阻塞；保留单一 Manager 进度权威。
修改按需交接参考、Worker 模板及必要的入口和中英文说明，不新增协议字段、调度器
或 GitHub API 适配器，保持 alpha.2 和并行默认关闭。

用可复建的本地 Git 合成场景验证：新上下文作者根据原始项目与任务请求产出 Issue
正文；领取登记后，另一个新上下文 Worker 只接收 Issue 正文及技能入口，在未准备
工作目录的情况下获取固定基线、创建 worktree、完成有界任务并返回真实检查证据。
作者另准备一个依赖未就绪的 Issue，审查其阻塞条件，不执行该任务。使用本地文件
代替 GitHub 传输，不据此宣称真实 GitHub API、并发抢占或取消/重启已验证。

验收：检查实际 Issue 和 Worker 产物、正确基线、写入范围、命令与退出码、Manager
权威及阻塞说明；运行完整自动化回归和技能格式校验，保留源码指纹和观察记录。
合成试用准备器的确定性测试与独立 Agent 行为观察分开记录。全部修改由 root 汇总
检查，本轮不需要重复设置终验任务。保留此前计划和检查的原始字节。
